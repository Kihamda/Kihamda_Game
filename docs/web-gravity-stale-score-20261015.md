# GravityBallの古いタブからの最高値保護

2026-10-15の13時枠。旧実hookで初期20→別タブ相当500→100更新を行うと、保存値が100まで下がることを再現した。保存と失敗再試行の直前に既存値を読み直し、画面内最高値との最大値を保持する。読込が途中で拒否された時も未保存として案内し、元データを上書きせず復旧する。別タブの高い値を見つけた時は新記録成功を返さない。

実hookで古い値、書込拒否中の別タブ更新、初期成功後の読込拒否/復旧を検査した。最終本番Chrome2タブの127.0.0.1:4217で、20読込後に別タブから50000を保存し、古いタブの低い最終得点3962によって値が下がらないことを確認。次に書込拒否の検査用最終状態から約63000を未保存にし、別タブから80000を保存した。拒否中の再試行は80000を保持し、API復旧後のEnter再試行も80000を保持した。警告解除とゲームへのフォーカス復帰、両タブ再読み込み後の80000を確認した。
