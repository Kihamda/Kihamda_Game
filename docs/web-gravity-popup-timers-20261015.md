# GravityBallの再開始後の遅延演出取消

2026-10-15の13時枠。旧実Appで全クリアから再開始した後、および通常ステージ通過直後にunmountした後に、遅延した得点演出timerが残ることを確認した。既存検査は遷移timerだけを確認していた。

得点、最高記録、全perfectの遅延演出をSetで保持し、発火時に外し、再開始とunmountで全解除する。再開始時のpopup queueと表示解除は維持した。既存の遷移timerと表示終了timerは従来の個別解除を維持する。実App回帰では再開始後とunmount後の全timer=0を確認した。検査用timerは単調増加IDと発火時の自動除去へ合わせ、実ブラウザのtimerに近づけた。

Chrome1280の最終本番版で最終ステージ状態/得点/perfect4を注入し、2回のrequestAnimationFrame後にphase=cleared、遅延演出4件を読み取った。同じ呼出内の通常UI Enterで再開始し、phase=start、演出0件を確認した。最初の試行は操作前に演出が終了して0件だったため、取消の証拠には使わず、待機4件のある再試行を採用した。通常完走とfixtureは区別する。
