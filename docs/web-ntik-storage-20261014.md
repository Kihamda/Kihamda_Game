## 修正前の再現

実際のstorage.tsをバンドルして例外を注入すると、3×3設定に1×1の盤面・手番99でも読み込まれた。setItem失敗はconsoleだけへ出力され戻り値undefined、removeItem失敗は呼出元へ例外が伝わった。

## 変更

保存を読み込む前にappState、設定の寸法・勝利条件・プレイヤー、盤面の行列数・各マス、手番・勝者の形式を照合する。gameModeがない正常な旧保存はclassicとして維持する。不正データを自動削除せず、新ゲームによる置き換えを画面で知らせる。保存・設定保存・削除は成否を返し、失敗をGameShellの縮小されないstatusへ表示する。削除失敗時はリロードせず、ゲームと保存を維持する。新ゲーム・再開時は過去の削除失敗案内を解除する。
