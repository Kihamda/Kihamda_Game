# Web入口の検索条件保持と自律作業方針

2026-10-12の本人の追加指示で既存T-web-portal-navigation-stateを実装した。検索語qと公開フィルターfilterをURLに保存し、作品詳細URLと一覧リンクへ引き継ぐ。文字入力・絞り込み・解除は現在の履歴項目を更新する。Cookie・localStorageに依存せず、ブラウザの戻る/進む・再読み込み・直接詳細訪問を扱う。静的生成では空の条件を使いwindowを参照しない。

## 実ブラウザの検査

- 1280×720でUnityを文字入力、Enterで詳細、戻る、進む、Enterで一覧へ戻る。検索Unityを保持し、明示一覧は#worksにフォーカスした。
- Unity＋公開中は0件。再読み込みで両条件を保持。解除ボタンは両条件を消す。
- 390×844で配送の詳細移動、戻る、再読み込み。日本語検索を保持。Tabで検索から詳細リンク、Enterで詳細と一覧へ移動できた。
- 空白・<>・&・+・引用符を含む検索語を再読み込みして同一文字列を復元。未知のfilterは表示上allになり、次の入力と生成リンクでは未知値を除く。
- 検索と公開中を持つ詳細を直接開いてから一覧へ戻ると、両条件を復元。条件なしの直接詳細は/#worksへ戻り、空検索になる。
- 配送へabcdeを逐次入力してから一度だけ戻ると前の詳細へ到達し、進むと配送abcdeの一覧になる。文字ごとに履歴が増えていないことを実操作で確認した。
- 一覧・詳細に横はみ出しなし。release=nullに開始リンク・iframeなし。実タッチ、Safari、人間評価、ゲームの保存検査とは区別する。

## 自動検査と保全

TypeScript、ESLint、Vite、5静的ページ生成、旧4URL・GUID19件・36成果物チェックサムが成功。新しいcheck-portal-navigation.mjsは実コンポーネントのSSRで検索・詳細/一覧URL・公開フィルター・条件なし詳細・未知フィルター・危険な検索文字のエスケープ・未公開開始リンクなしを確認する。CIにも追加した。事業台帳27テスト、既存CourierCore全3ルートのルール検査が成功。CourierCoreには既存CS8603警告があるが、今回はUnityの再ビルド・制作をしていない。

本人の追加許可をAGENTS.md・studio-policy・定期実行unityへ保存。短い調査だけで終了せず、時間内に実装・ブラウザ検査・CI確認・PR反映を進める。既存25分checkpoint/30分保存・WIP1・サブエージェント禁止は維持。Unity CIは設定と手動起動を保全し、main pushによる追加ビルドを止めた。Web方針へ変更した後に、過去の保全ソースが含まれるPRのマージだけでUnity配布ビルドを再開しないため。
