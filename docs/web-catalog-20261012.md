## データと公開の条件

正本はweb/src/portal/data/works.json。technologyはweb/unity、originはstudio-web/owner-finished/preserved-prototype、statusはdevelopment/paused/verification。release=nullは未公開で、開始リンクを出さない。公開状態は制作技術から推測しない。

releaseには同じサイト内の配布URL、version、platform、SHA-256、verification、distributionPermission、recoveryを記録する。記録が不完全な場合、型・実行時検査で公開データを拒否する。これらの文字列が埋まっているだけで動作検証や配布許可が成立するわけではない。受領後に実物と根拠を照合して登録する。本人持込Unity完成品にソース提供・再ビルドを一律要求しない。

既存Unity試作品Ice Courierは制作停止・保全中。release=nullを保持した。Unity本体、設定、既存ビルドと検査履歴は変更していない。ローカル検査入口のmanifest検証とloopback制限は保持し、説明を保全した旧試作品に合わせた。今回はローカルUnityの起動検査を再実行していない。

一覧・検索・詳細・運営案内・メタ説明を修正。作品ごとのfactsを表示し、別作品へIce Courierの3ステージや盤面を転用しない。詳細と静的生成の経路は作品データから選ぶ。実ブラウザで末尾スラッシュの違いによる作品未検出を発見し、修正後に再検査した。
