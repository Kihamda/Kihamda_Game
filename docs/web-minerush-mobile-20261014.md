# MineRushのモバイル操作検査

390×844の初期画面は変更前16.2px、敗北画面は共有・おすすめ欄により10.8pxまで縮小した。ゲーム本体を420×500へ調整し、勝敗を上部へまとめた。本番ビルドでは全81マスが24.516px、リセットと旗モードが32.688px以上。1280×720ではマス36px。全対象がゲーム枠内で、横のはみ出しなし。

Fで旗を切り替え、矢印で隣接マスへフォーカスする。Enterで開き、旗モードならEnter・タップで旗を切り替える。状態をマスの読み上げ名へ含め、フォーカス枠を追加した。長押し後のクリック重複、移動・キャンセル・複数指、リセット・アンマウント後のタイマーを実Appのイベント処理で回帰検査した。これは実タッチではない。

実Chromiumの本番ビルドでF、矢印、Enter、右クリック、旗モード、初手安全、敗北、リセット、再読み込みで全81マスへ戻ることを確認した。途中盤面を保存しない説明を維持する。共有・おすすめ欄は敗北画面から除いた。

共通枠は整数clientHeightの丸めで僅かにはみ出す問題も修正し、小数の実寸から縮小率を切り下げる。変更後のIce Slide、n目並べ、GravityBall表示の回帰は後続検査で確認する。

実機タッチ、Safari、人間評価、今回の実ブラウザでの全マス勝利は未確認。旧ルール検査を新しい実タッチ成功として扱わない。releaseと事業指標はnullのまま。
