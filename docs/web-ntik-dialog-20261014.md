# n目並べの確認操作とタイマー検査

設置確認をHTMLのモーダルdialogへ変更した。ゲーム枠の縮小を受けず、390×844と1280×720で幅340px、操作ボタン142×44px。初期フォーカスはキャンセル、Tab・Shift+Tabは確定とキャンセルを循環する。Escape・キャンセルでは元のマスへ戻り、確定後は無効になったマスの代わりに設定ボタンへフォーカスする。背景はモーダルの間操作できない。

本番ビルドの実Chromiumで3×3を設定し、Enterによる確認、Tab両方向、Escapeの取消と元マスへの復帰、Enter確定、直後の再読み込みでX着手とPlayer 2手番の保存を確認した。実画面は390px・1280pxの画像へ保存した。

手番移行・勝敗演出のタイマーを追跡し、設定へ戻る、新ゲーム開始、アンマウントで取り消す。実ブラウザで着手直後に設定へ戻り新ゲームを開始し、1.5秒後もPlayer 1・空盤面を維持した。実Appを読み込む回帰検査でも手番・勝利演出中の新ゲームとアンマウントを確認した。勝利演出取消は今回の実ブラウザでは未検査。

共通縮小変更の回帰として、390pxのIce Slideステージ1は最小操作対象28.608pxで枠内、2手クリア。GravityBallの画面は269.5×323.4pxで枠内、Enter開始を確認した。前回の全20盤面・全5ステージ検査は過去の証跡として区別する。

大盤面の24px未満のマス、設定画面の小さな操作部、代替操作、Safari・実タッチ・人間評価は未完了。次は同じモバイル工程で大盤面の拡大または座標指定を整える。事業指標とreleaseはnullのまま。
